# Vibrant Mehendi Celebration

A separate, responsive wedding invitation concept for Noor and Zayn, built with Vite and original generated Pakistani Mehendi photography.

## Preview locally

```powershell
cd "C:\Users\Ayan\Documents\Invitation Design\projects\vibrant-mehendi-celebration"
npm.cmd install
npm.cmd run dev
```

Open the local address shown in the terminal.

## Production build

```powershell
npm.cmd run build
```

## RSVP delivery

The RSVP flow validates, celebrates with confetti, and saves a local copy in the guest's browser. To receive replies online, add a form service URL to the `data-endpoint` attribute on `#rsvp-form` in `index.html`.
